# Syncthing

## Open-Source Continuous File Synchronisation

Syncthing synchronises files between two or more computers in real time. It
is safe, secure, and fully peer-to-peer. Every node is identified by a
strong cryptographic certificate, and all communication is encrypted with
TLS.

Syncthing is developed and maintained under the [Syncthing
Foundation](https://www.syncthing.org/), a Swedish non-profit.
